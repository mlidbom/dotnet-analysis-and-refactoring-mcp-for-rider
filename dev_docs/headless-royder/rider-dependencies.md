## Open questions for the running host

1. Which implementation actually resolves for `IDocumentStorageHelpers`, `ISolutionHost`, `IPsiCachesState` and `ITextControlManager`? Do tool enumeration, peer registration and a known-symbol query all succeed? This distinguishes composition failures from missing symbols.
2. Does a default CLI-backed worktree absorb external content changes and changes to SDK globs, reference graphs and restored/generated files over its lifetime? Which change requires `CommitChanges`, targeted project reload, or reopening the solution? Can the first query after each change prove the state is current?
3. Does the in-process control place the caret correctly on a real project document? Which bulb actions can finish without a picker, template session or navigation UI? Compare a known completion, a noninteractive quick fix, and a fix that requires a choice.
4. Which settings layers and language/inspection providers are active? Compare an EditorConfig severity, a solution-level style, a compiled type with the effective decompiler setting, and one completed SWEA-only result. F# support would require a separate plugin compatibility check.
